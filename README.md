# AI-Powered Supply Chain Copilot

An AI-powered Supply Chain Decision Support System built using Python, FastAPI, Google Cloud Platform (BigQuery, Vertex AI), Gemini, LangGraph, and Retrieval-Augmented Generation (RAG).

## Tech Stack

- Python
- FastAPI
- React
- Google Cloud Platform (GCP)
- BigQuery
- Vertex AI
- Gemini
- LangChain
- LangGraph
- Docker
